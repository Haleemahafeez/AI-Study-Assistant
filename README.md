# AI Study Assistant 🤖

## About the Project
AI Study Assistant is a beginner-friendly AI project built using Python and the Google Gemini API. It helps students understand programming concepts, learn about Artificial Intelligence, and create study plans.

## Features
- Answers study-related questions
- Explains Python and Computer Science concepts
- Provides beginner-friendly explanations
- Creates personalized study plans
- Supports interactive question-and-answer sessions

## Technologies Used
- Python
- Google Gemini API
- Google Colab

## How to Use
1. Open the project notebook in Google Colab.
2. Enter your Gemini API key when prompted.
3. Ask a study-related question.
4. Read the AI-generated response.
5. Type `exit` to stop the assistant.

## Learning Objectives
This project was created to practice Python programming, API integration, and the use of generative AI in education.
